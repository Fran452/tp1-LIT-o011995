## Decisiones técnicas

- Vite
- Lit
- HTML

- JavaScript
- @vaadin/router (Con ayuda de GPT)
### Explicacion
La entrega del TP esta armado enteramente usando la teconologia de lit con una base de vite para la estructurazion del proyecto. El mismo utiliza @vaadin/router para el ruteo de las diefentes paginas y asi mismo para los estilos y el funcionamiento correcto del ruteo se utilizo Codex 5.5 como ayudante de IA.
Demtro del proyecto tambien se uso componentes de Dile Components para darle mas estructura al mismo
## Ejecucion del proyecto
Para ejecutar la web se tiene que seguir las siguientes intrucciones:
1) Entrar al proyecto con cd 
2) npm i -> De no tener el node_modules
3) npm run dev -> Para iniciar el proyecto
4) Luego entrar al link salido por pantalla
